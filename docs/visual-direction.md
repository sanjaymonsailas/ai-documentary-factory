# Zombie Horde — Visual Direction

## Reference

Primary visual reference: the supplied concept image generated for Zombie Horde.

The target is a polished, colorful, isometric 3D cartoon game with the visual clarity of a modern hybrid-casual mobile title.

## Composition

- High 3/4 isometric view
- Road or path is the dominant compositional axis
- Horde occupies the lower center
- Gate choices are large and legible
- Enemies and hazards use strong silhouettes
- Final base is visually important
- The camera gently follows the crowd

## Character language

Zombies should be:
- chunky
- expressive
- immediately readable
- varied by silhouette
- cute rather than grotesque

Walker = rounded balanced body
Runner = lean and fast
Tank = wide and heavy

## Environment

The world should feel dense, not empty:
- roads
- sidewalks
- buildings
- windows
- trees
- street lamps
- parked vehicles later
- fences and props later

Keep geometry simple enough for browser performance, but use intentional material, lighting and composition.

## Color language

Environment:
- cool blue sky
- warm building accents
- green vegetation
- neutral asphalt

Player army:
- luminous greens
- light outlines/glow accents

Hazards:
- orange/red

Positive gates:
- cyan / green

Enemy defenses:
- steel / navy

UI:
- dark glass panels
- bright green action buttons
- large white typography

## Polish checklist

A feature is not visually finished until it has:
- clear silhouette
- consistent material language
- readable scale
- animation or motion cue
- feedback when interacted with
- clean spacing
- mobile readability

## Do not

- use primitive blocks as the final art
- create giant empty fields
- use random art styles
- use tiny unreadable text
- add gore
- make UI resemble business software
