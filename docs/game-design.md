# Zombie Horde — Game Design

## Product identity

A hybrid-casual crowd-action game with a zombie fantasy.

### 30-second loop
Aim the spawn point, pass through better gates, survive hazards, watch the crowd explode in size, break the enemy base.

### 5-minute loop
Finish levels, earn coins, improve starting count, select a stronger zombie type, unlock the next district.

### Long loop
Zombie collection, mutations, heroes, new worlds, boss sieges and live events.

## Controls

Desktop:
- A / D
- Left / Right Arrow
- Mouse drag

Mobile:
- horizontal drag

The player never has to micromanage individual zombies.

## Level rhythm

Each level should have:
1. A safe intro
2. A first multiplier decision
3. An obstacle
4. A harder gate
5. A defense group
6. A final base encounter

Avoid making the highest multiplier mathematically dominant every time. The best route should depend on the risk in the lane.

## Progression

Current prototype:
- Coins
- Starting-count upgrade
- Walker / Runner / Tank selection
- Local save

Planned meta:
- Zombie fragments
- Evolution
- Heroes
- World map
- Boss sieges
- Daily challenge
- Limited-time events

## Design constraint

The crowd is the product. Every new feature should make the crowd feel larger, faster, smarter or more satisfying.

Do not dilute the game into menus.
